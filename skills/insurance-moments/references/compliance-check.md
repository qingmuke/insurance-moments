# 命题审查清单（合规版专用）

写合规版之前，先用本清单对素材做一遍审查。审查结果不输出，只作为创作依据。

## 第一步：提取核心判断

从用户素材里找出最关键的那句话。通常是：
- 一个产品卖点（"确诊即赔""保证续保20年"）
- 一个经验结论（"理赔不难""买保险要趁早"）
- 一个案例推论（"客户3天赔了8万→这家公司理赔好"）

如果素材里没有明确判断，只有事实描述，审查直接通过，正常创作。

## 第二步：逐项检查五种逻辑坑

### 1. 绝对化

**检查**：有没有"一定/都/从来/任何/只要…就…/百分百/所有"这类词？

**保险常见场景**：
- "这个产品什么都赔" → 实际上有免责条款
- "买了就不用担心" → 实际上有保额、责任范围限制
- "确诊就赔钱" → 实际上只有约定病种确诊即赔

**处理**：加上限定词。"什么都赔"→"合同约定的责任范围内都赔"；"买了就不用担心"→"在保额范围内，这笔钱能帮上忙"。

### 2. 因果跳跃

**检查**：A 真的能直接推出 B 吗？中间有没有其他必要条件？

**保险常见场景**：
- "买了重疾险→得了大病不用愁" → 中间隔着保额够不够、责任在不在范围内
- "保证续保→理赔有保障" → 保证续保解决的是"能不能续"，不是"赔不赔"
- "一个客户理赔成功→保险理赔不难" → 一个案例不能推出全局

**处理**：只说能确定的部分，不跳结论。或者把中间条件补上。"买了重疾险→在合同约定的重疾和保额范围内，有一笔确定的钱可以用"。

### 3. 定义偷换

**检查**：有没有把 A 概念偷偷换成 B 概念？

**保险常见偷换**：

| 原概念 | 被偷换成 |
|---|---|
| 保证续保 | 保证理赔 |
| 保证续保 | 保费不涨 |
| 确诊即赔 | 所有确诊都赔 |
| 免责条款少 | 什么都保 |
| 理赔速度快 | 理赔容易 |
| 产品停售 | 老客户也不能续 |
| 分红险 | 保本保收益 |
| 万能险 | 保底利率以上都保证 |

**处理**：用准确术语。必要时主动区分两个概念，比如"保证续保解决的是明年还能不能买，不是明年赔不赔"。

### 4. 以偏概全

**检查**：一个案例、一个客户、一次经历，能代表全局吗？

**保险常见场景**：
- "我客户3天赔了8万" → "这家公司理赔好"
- "邻居被拒赔了" → "保险都是骗人的"
- "一个产品停售了" → "这类产品都要停"
- "我用不上" → "这个产品没用"

**处理**：保留案例，删掉全局结论。或者加限定词"这次""这个案例里""我遇到的这个客户"。

### 5. 反向推断

**检查**：有没有从"没发生"推出"好"，或从"发生了"推出"坏"？

**保险常见场景**：
- "5年没理赔" → "保险白买了"
- "没出险" → "产品好"
- "理赔被拒" → "保险都是坑"
- "身边没人得病" → "重疾险没用"

**处理**：只陈述事实，不做反向归因。重新定义价值："5年没理赔，不是白买，是这5年平安。"

## 第三步：确定处理方式

审查完后，对每个命中的坑确定处理方式：

| 情况 | 处理 |
|---|---|
| 命题成立，没有坑 | 正常写，保留原判断 |
| 案例成立但结论过度 | 缩小边界：保留案例，删掉过度结论 |
| 概念被偷换 | 换回准确概念，必要时主动区分 |
| 绝对化表述 | 加限定词，或换成"在合同约定范围内" |
| 命题不成立且无素材支撑 | 换成中性表述，不编不造 |

## 合规版创作原则

合规版不是"把话写得模棱两可"，而是"把大话缩成实话"。

- 力度可以保留，但边界必须清楚
- 可以有态度，但态度要建立在准确的事实上
- 可以戳痛点，但不能用虚假的恐惧来戳
- 可以给建议，但建议不能基于错误的前提

记住：保险是强监管行业，朋友圈写出去的每句话都可能被截图当证据。合规版不是锦上添花，是保命的。
